# NuerisupuBytecode
C'est le lingua Nuerisupu. C'est ne 1 a 1 en Francais, mais je veux a regarde le Francais quand je veux.

Du journal, le lingua de Ruby est temporaire a je encrire un version en CrystalLang, ou pour un polyglot systeme.

( This isn't to replace Awasunu or Nuerisupu, but rather have an alternative route into Nuerisupu, ala naked lisp. )

## Usage
Write your first greeter script.

~~~
(enc "Bonjour! Toute le monde!")
~~~

## Detailed Example
Determines a character's outfit and makes genetic trait predictions.

~~~clisp
------------------------------------------------------------------------------
--                                MC Outfits                                --
------------------------------------------------------------------------------
-- Assign a character outfit to Ehena Marie.                                --
------------------------------------------------------------------------------
(arc "rouge" "belle" "grande")
(cor "rose" "belle" "grande")
(jup "blue" "chien" "grande")
(sab "braun" "lump" "petite")

------------------------------------------------------------------------------
--                                 Genetics                                 --
------------------------------------------------------------------------------
-- This covers genetic trait prediction by evolving different combination   --
-- of traits.                                                               --
------------------------------------------------------------------------------
(obe3 red_hair green_eyes fair_skin)
(obe3 braun_hair blue_eyes fair_skin)
(obe3 blond_hair green_eyes medium_skin)
(sca)
~~~
